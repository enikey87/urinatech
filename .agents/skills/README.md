# Скилы агентов

Каноническое место скилов — этот каталог, `.agents/skills/`. Он не принадлежит
ни одной оболочке агента: файлы здесь — единственный источник, правки вносятся
только сюда.

Каталоги конкретных оболочек содержат симлинки на скилы:

- `.zcode/skills/<имя>` → `../../.agents/skills/<имя>` (ZCode)
- `.claude/skills/<имя>` → `../../.agents/skills/<имя>` (Claude Code)

Новая оболочка подключается одним симлинком на существующий скил; копий файлов
в нескольких местах не плодить — они разъедутся.

## Состав

- `factory-lead` — ведущий «фабрики»: контент → документы → задачи, аудит PR
  агентов, опросник решений автора, отчёты. Чек-лист аудита — `AUDIT_BRIEF.md`
  внутри.
- `agent-task` — элемент роя: берёт одну задачу из очереди issues (метка
  `task`) и доводит её до мержа. Запуск: `/agent-task <имя>`.
- `agent-task-loop` — цикл-оркестратор: непрерывно разбирает очередь рабочими
  подагентами, при пустой очереди — polling с растущим интервалом. Запуск:
  `/agent-task-loop <имя>`.
- `generate-patient-photos` — генерация ИИ-аватаров «пациентов» для отзывов.
