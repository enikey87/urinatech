# УринаТех

Производственно-исследовательская компания полного цикла. Русская моча против
скальпеля врача. Непрерывный производственный контроль качества с 1246 года.

Сайт-реставрация легендарного ресурса `urina-ru.narod.ru` (Московский Институт
Обогащения Урины, 2002): концепция, ассортимент и правовая позиция оригинала
сохранены и приведены к современным отраслевым стандартам.

> Имеются противопоказания. Необходима консультация специалиста. 18+

## Технологический стек

- TypeScript (strict)
- React 18
- MobX 6 (mobx-react-lite)
- Vite 6

## Разработка

```bash
npm install
npm run dev        # локальный сервер, http://localhost:5173
npm run build      # типы + продакшен-сборка в dist/
npm run preview    # предпросмотр продакшен-сборки
```

## Публикация

Публикация выполняется автоматически через GitHub Actions при пуше в `main`:
сборка и деплой на GitHub Pages. Настройки Pages: Source → GitHub Actions.

## Структура

```
src/
├── components/   # секции сайта и элементы интерфейса
├── stores/       # MobX-сторы: корзина, верификация, донорская программа, отзывы
├── data/         # каталог продукции, тарифы, правовая позиция, стратегия
└── styles/       # глобальные стили
```
