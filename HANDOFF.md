## 1. Что это за проект (суть в одном абзаце)

Сатирический сайт-пародия на псевдомедицину. Первоисточник — легендарный мем
Web 1.0 «Русская моча против скальпеля врача» (urina-ru.narod.ru, 2002,
Московский Институт Обогащения Урины, свёрстан в FrontPage). Мы реставрируем
его как современный сайт вымышленной компании **ООО «УринаТех»** с дочерним
**Пансионатом «Солнышко»**. КРИТИЧНО: юмор строится на **мёртво-серьёзном
официальном тоне** — ни одной открытой шутки, только канцелярит, ГОСТы,
«зафиксировано в карте», «уведомлён письмом». Смешно именно отсутствие смеха.
Пародия направлена ПРОТИВ псевдомедицины (дисклеймеры 18+/«не является
лекарственным средством» есть и сами являются гэгом).

- Продукты: **УТ-01 «Утренний»** (сбор 04:00–05:40 МСК), **УТ-02 «Эталон»**

## 4. Стек и архитектура

- **TypeScript (strict) + Vite 6 + React 18 + MobX 6 (mobx-react-lite)**. Никаких
  router-библиотек: **хеш-роутинг** через `RouterStore` (`#/` ↔ `#/solnyshko`),
  работает на GitHub Pages без сервера. ВСЁ, что читает observable в рендере,
  должно быть обёрнуто в `observer` — иначе хеш-навигация не перерисует экран
  (был баг с App, уже исправлен).
- Сторы (`src/stores/`): Cart, Detector (верификация партий), Donor, Testimonials,
  Ticker (биржа $MOCHA, обновляется 2.5с), Countdown (до 2374, тикает 1с),
  Calculator (дозировка), Chat (Зинаида), Poll, Cookies, Router, Solnyshko (путёвки).
  Корень: `createRootStore()` + `RootStoreContext` + `useStore()`.
- Данные контента вынесены в `src/data/catalog.ts` (основной) и
  `src/data/solnyshko.ts` (пансионат) — правки контента почти всегда только там.
- 404: `public/404.html` кладёт путь в `sessionStorage("ut-redirect")` и делает
  `location.replace("/urinatech/")`; `main.tsx` читает флаг ДО рендера (StrictMode
  дважды вызывает lazy-initializer useState — читайте вне компонента!) и передаёт
  пропсом `initialNotFound` в App.
- `vite.config.ts`: `base: mode === "production" ? "/urinatech/" : "/"`. Все ссылки
  на статике — через `import.meta.env.BASE_URL`.
- Деплой: GitHub Actions `.github/workflows/deploy.yml` (npm ci → build →
  deploy-pages), Pages включён в режиме Source: GitHub Actions. Пуш в main =
  автодеплой (~40с). Отменённый run из-за concurrency — норма: задеплоит следующий.
- В репо есть параллельная активность (agent-task-фабрика, скиллы
  agent-task/agent-task-loop в `.zcode/skills`/`.agents/skills`) — перед пушем
  делать `git pull --rebase`, push может быть отклонён.

## 6. Know-how: ловушки, на которые мы уже наступили

1. **Генерация картинок, проверено 2026-10:**
   - Pollinations.ai — бесплатно/без ключа, но ВОДЯНОЙ ЗНАК на free-tier всегда
     (nologo=true не работает). Не использовать.
   - AI Horde — анонимам 403. Не использовать без ключа.
   - HF Spaces FLUX.1-schnell — отлично, но анонимная ZeroGPU-квота ≈ 2 картинки/
     день; с бесплатным HF-токеном больше. gradio_client: `Client(space)`,
     `predict(prompt, seed, randomize_seed=False, width=256, height=256,
     num_inference_steps=4, api_name="/infer")`.
   - Локально на x86 Mac (i9/32GB/Radeon 4GB): только SD1.5 на CPU (~2.5 мин/шт).
     Пины: python3.10 (НЕ системный 3.14 — под него нет torch), torch==2.2.2
     (последний под x86 macOS), diffusers==0.27.2, transformers==4.41.2,
     huggingface_hub==0.23.2, numpy==1.26.4. Realistic Vision V5.1 падает с
     `final_sigmas_type zero is not supported for algorithm_type deis` на
     diffusers 0.27 → шедулер брать `from_pretrained` базового SD1.5 и передавать
     в пайплайн параметром `scheduler=`.
   - Поисковик отказывает по запросам про лечение детей мочей — не искать,
     спокойно берём остальную фактуру.
   - Habr/обзорные статьи про «бесплатные нейрогенераторы» часто ведут к
     Pollinations-подобным сервисам с вотермарками — проверяйте картинку
     визуально ДО массовой генерации (у нас CDN-загрузчик изображений показывал
     КЭШ старой картинки под тем же именем — проверяйте под уникальным именем
     файла или по EXIF/типу данных через `file`).
2. **Браузерная автоматизация (IAB + playwright-фасад):**
   - Постоянные анимации (marquee/тикер/коловрат) роняют actionability-проверки
     locator.click — кликайте через `evaluate(() => el.click())`.
   - Один evaluate дольше ~25–30с упирается в 32с-таймаут IAB — длинные циклы
     разбивать на короткие вызовы.
   - `goto` на тот же URL НЕ перезагружает страницу (SPA остаётся в памяти со
     старым бандлом после смены кода) — нужен `reload()` или новая вкладка.
   - Dev-сервер, запущенный как фоновая задача сессии, может умереть при
     перезапуске — надёжнее `nohup npm run dev > /tmp/vite_dev.log 2>&1 &`.
   - Кэш модулей Vite в открытой вкладке живёт своей жизнью; при странных
     расхождениях DOM vs curl — сначала reload новой вкладкой.
3. **Git:** в репо пушит и «фабрика» (agent-task loop) — всегда `git pull --rebase
   origin main` перед push; чужие коммиты в истории — норма. Concurrency в
   workflow (`group: pages, cancel-in-progress: true`) отменяет ваш run, если
   пришёл более свежий пуш — проверяйте последний run в списке.
4. **Контент-тема:** слово «моча» и капля — ЗОЛОТО (#a87200 / #e2a41f), красный —
   только штампы/служебное. Пользователь это явно просил.

## 9. Чек-лист новой машины

```bash
git clone git@github.com:enikey87/urinatech.git && cd urinatech
npm install
npm run dev          # localhost:5173
npm run build        # типы + прод-сборка; base подхватится сам
git pull --rebase origin main && git push   # после изменений
```

Правило правок контента: 95% случаев — только `src/data/*.ts`. Правило тона:
сначала напиши фразу нормально, потом замени все слова на канцелярит. Если
фраза смешная сама по себе — она не подходит.
