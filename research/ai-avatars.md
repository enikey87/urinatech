# Исследование: генерация фотореалистичных аватаров для отзывов

**Дата:** 24.10.2026
**Задача:** подобрать способ получения фотореалистичных портретов-аватаров
несуществующих людей для карточек отзывов (сейчас в `TestimonialsStore` — эмодзи).
Наш стек: статический сайт на Vite + React + GitHub Pages, т.е. аватары — это
статические файлы, сгенерированные один раз на этапе разработки и закоммиченные
в репозиторий (никакого рантайм-генерирования не нужно).

## 1. Категории решений

### A. Специализированные сервисы «лиц несуществующих людей»

| Сервис | Что даёт | Цена / лицензия |
| --- | --- | --- |
| [Generated Photos](https://generated.photos/faces) | Лидер ниши: генератор лиц + готовые датасеты, фильтры (возраст, этнос, эмоция), **API**, полные тела | Триал 3 дня; коммерческая лицензия от $19.99/мес (~$199/год, ~15 загрузок/мес), пакеты от $250/мес |
| [thispersonnotexist.org](https://thispersonnotexist.org) | Бесплатные случайные лица: пол, раса, возраст, эмоция; 8 HD-фото за раз, есть full-body | Бесплатно; лицензию проверять на месте |
| thispersondoesnotexist.tools | Простой бесплатный онлайн-генератор лиц | Бесплатно, «personal and broader use» по своим terms |
| thispersondoesnotexist.com | Оригинал на Nvidia StyleGAN (2019) | Домен выставлен на продажу — будущее туманно |
| Fotor, HeadshotPro, ProfilePicture.ai, Astria, Artflow | Генераторы «аватарок/хедшотов», чаще заточены под фото реального человека в разных ракурсах | Подписки; для несуществующих людей избыточны |

### B. Универсальные нейрогенераторы (текст → фото)

По обзорам 2026 года лучшими в фотореализме считаются: **GPT Image 2.5**,
**Google Imagen / Nano Banana 2.1**, **FLUX.2 / FLUX Pro (Ultra до 4MP)**,
**Midjourney**, **Adobe Firefly**, **Seedream / Hunyuan (Tencent)**. Плюс:
промптом задаём точный образ («женщина 54 лет, г. Кимры, фотография на паспорт,
нейтральный фон») — получаем не случайное лицо, а точно под персонажа отзыва.
Минус: подписка, у Midjourney права на коммерческое использование — только
платный тариф.

### C. Open-source модели локально / через Hugging Face

| Модель | Комментарий |
| --- | --- |
| FLUX.1 / FLUX 2 (dev / schnell / pro) | Топ фотореализма среди открытых весов; dev — некоммерческая лицензия, schnell — Apache 2.0 (проверять актуальную лицензию версии) |
| Z-Image (6B) | Новый эффективный открытый модель, скромные требования к VRAM |
| Hunyuan Image 3.0 (Tencent) | Флагманский открытый конкурент FLUX |
| Qwen-Image / Wan (Alibaba) | Сильное качество при умеренном железе |
| SD 1.5 / SDXL + портретные файнтюны (Realistic Vision, Juggernaut) | Классика; проверенные чекпойнты под портреты, огромная экосистема LoRA; по «сырому» фотореализму уже уступают FLUX-семейству |

Запуск: локально через ComfyUI / Automatic1111 (нужна GPU) или **бесплатно в
Hugging Face Spaces** — без железа и установки. Для нас это самый дешёвый путь:
генерируем 8–10 лиц, скачиваем, коммитим.

## 2. Практический пайплайн под наш проект

1. Сгенерировать портреты (любой вариант выше; промпт: `passport-style photo of
   a [возраст/пол], neutral expression, plain background, square crop`).
2. Кадрировать 1:1 по лицу, ресайз до **128×128** (в карточке рендерятся 48px —
   запас под retina).
3. Конвертировать в **WebP** (~5–10 КБ/шт; 10 аватаров ≈ 80 КБ — незаметно
   для бандла).
4. Положить в `public/avatars/review-1.webp … review-10.webp`.
5. В `TestimonialsStore` заменить поле `avatar: "👩‍🦳"` на `avatar: "/avatars/review-1.webp"`
   (в проде — путь `/urinatech/avatars/...`, учесть `import.meta.env.BASE_URL`).
6. В `Testimonials.tsx` рендерить `<img>` вместо эмодзи (стиль `.review-card__avatar` уже есть).
7. Добавить дисклеймер: «Аватары отдыхающих/пациентов сгенерированы нейросетью;
   совпадения с живыми людьми случайны и статистически невероятны» — в тоне
   сайта это отдельный гэг.

## 3. Этика и право (коротко)

- Лица синтетические (не дипфейки реальных людей) — основная юридическая
  проблема отсутствует, но в ряде юрисдикций использование синтетических лиц
  в «отзывах» требуют раскрывать; честнее и смешнее подписать.
- Лицензии сильно разнятся: у бесплатных генераторов коммерческое использование
  почти всегда только на платном тарифе; у открытых весов смотреть лицензию
  конкретной модели (FLUX dev — non-commercial, schnell — Apache 2.0,
  SD — OpenRAIL-M++ позволяет коммерцию).
- «Эффект разоблачения»: аудитория относится к найденным ИИ-лицам в отзывах
  негативнее, чем к честно подписанным ИИ-аватарам (материалы stills.com).

## 4. Рекомендация для «УринаТех»

Для пародийного сайта с открытым кодом оптимален вариант **C через Hugging
Face Spaces**: бесплатно, промпт-контроль под персонажей (Ковальчук 54 года,
дядя Женя из гаражного кооператива, коллекционер в тёмных очках), лицензия
коммерчески безопасных весов (FLUX schnell / SDXL), ноль зависимости в рантайме.
Запасной быстрый вариант — Generated Photos (чистая коммерческая лицензия,
API, фильтры «возраст/этнос/эмоция» прямо под наши персонажи).
