# Бриф аудита PR агента (mu-hospital)

Чек-лист ведущего для проверки PR агента-исполнителя. Проверка — по смыслу:
собирается ли, выглядит ли как сайт, не сломан ли соседний раздел. main = прод
(GitHub Pages), поэтому «собралось» — необходимый, но не достаточный барьер.

## Что проверить

### 1. Сборка и типы

```sh
npm ci && npm run build   # tsc -b (strict, noUnusedLocals) + vite build — обязаны быть зелёными
```

- В диффе нет `any`, `as unknown`, `@ts-ignore`, `@ts-expect-error`, правок
  `tsconfig.json` — это класс W (обход проверки).
- Не появились неиспользуемые импорты/переменные (упадёт `tsc`, но проверить).

### 2. Живой просмотр — оба сайта, два размера

```sh
npm run dev -- --port 5199   # в worktree PR, отдельный порт
```

Пройти в браузере:

- **Основной сайт:** рендер без ошибок в консоли; навигация по якорям ведёт на
  существующие `id`; бургер открывается на узком экране; корзина/чат/детектор
  работают (если затронуты).
- **Переход `#/solnyshko` и обратно** (`router.goMain()`) — не сломан.
- **390px и 1440px:** `document.documentElement.scrollWidth === clientWidth`
  (нет горизонтального скролла); сетки не схлопываются; ничего не наезжает.
- Дизайн-язык выдержан: основной сайт — «Техдок ГОСТ», «Солнышко» —
  «Советская путёвка». Новый CSS лежит в `global.css` / `solnyshko.css`
  по принадлежности, классы следуют локальному неймингу (БЭМ-подобные
  префиксы секции).

### 3. Контент и факты мира

- Каждая шутка опирается на факт мира (1246, партии `УТ-*`, Зинаида,
  ГОСТ/ТУ-реквизиты) — либо явно вводит новый факт, а не висит в воздухе.
- Тон раздела совпадает с канцелярско-протокольным стилем сайта.
- Дисклеймеры (18+, «не является лекарственным средством», «имеются
  противопоказания») не удалены и не превращены в шутку.
- Нет реальных людей, названий реальных клиник, фотографий реальных людей
  (аватары — только ИИ-генерация по `.zcode/skills/generate-patient-photos`).

### 4. Пути и ассеты

- Новые ассеты подключены через `BASE_URL` (прод — подпуть `/urinatech/`),
  не прямым `/путём`.
- Файлы лежат на месте: аватары — `public/avatars/`, данные — `src/data/`.

### 5. Соседнее

- PR не сломал смежные секции (общие стили `global.css` касаются всех).
- «Закрыто #N» в описании PR сверяется с целью issue, а не с описанием PR.

## Выход

На каждый PR:

- вердикт: A / B / C / W (критерии — «Маршрут задач по агентам» в SKILL.md);
- ревью комментарием в PR с подписью «Аудит по протоколу фабрики»;
  блокер — с первой строкой «**Не мержить до исправления**»;
- серьёзное (видит посетитель / обход проверки) → issue `task` сразу;
  спорное → issue `question`; остатки «на будущее» → строка «остаток без
  задачи» в журнал раунда;
- строка в `docs/audit-log.md`: PR → оценка → вердикт → номера задач.
